## Promote through the trust ladder

Run every proposed target version and every increase in D2 merge authority through the same sequence. Start with synthetic benchmark replays and shadow decisions recorded by the existing eval or dry-run harness. Move to live release smoke in synthetic repositories, including safe exact-head arming only after the branch probe. Then run about three real issues at limited volume and inspect their scorecards. Expand to normal volume only after three consecutive clean merges in the batch. Fix observed failures at their source and repeat earlier rungs with the resulting version. Keep authority limited by release, repository permission and admission rather than introducing a graph mode.
